# Carplay

Android 手机上的 CarPlay 风格桌面，支持应用窗口、导航卡片和音乐歌词。

## 下载

在本仓库的 **Releases** 页面下载 `Carplay-v54.apk`。当前版本：**v54**。

## 主要功能

- 横屏、竖屏布局，应用网格、Dock、主题、壁纸及大小设置。
- 应用全屏、分屏与窗口切换。
- 高德、百度原始导航卡片及路口放大图；采集失败时采用自绘卡片兜底。
- 音乐封面、播放控制、滚动歌词，以及导航和音乐悬浮卡片。

## 安装要求

- 最低 Android 13（API 33），targetSdk 35。
- 完整功能需要 Root 和兼容当前系统的 LSPosed。
- 在 LSPosed 中启用 Carplay，并按应用内提示启用系统框架及所用地图、音乐应用等对应作用域。
- 根据需要允许悬浮窗、通知使用权和相关系统权限。
- 安装或升级后建议重启手机，使相关进程重新加载模块。

本应用是独立桌面，车机连接和投屏由 AA-auto 等外部应用提供，APK 本身不负责建立 CarPlay、Android Auto 或 CarLife 连接。

## 升级

v51 及以后版本沿用同一签名，可覆盖安装；不同签名的旧安装包不能直接覆盖。卸载应用会清除其本地设置，请提前记录。

## v54 更新

- 原始卡片图片过大时尝试无损压缩，必要时等比缩小，保留完整内容和透明边缘。
- 原控件文字独立采集，图片暂时失败时仍能更新文字。
- 高德、百度固定和悬浮导航卡片采用一致的自绘兜底逻辑，不混入其他路段的旧文字；原图恢复后自动切回。
- 增加异步采集超时恢复、过期回调防护及失效诊断。

## 已知限制与反馈

不同系统、地图或音乐应用版本可能存在兼容差异，不能保证所有设备功能一致。v54 已通过 270 项自动化回归测试，实际地图进程与车机环境仍需实测。

如果原卡片文字本身持续读取失败，超过有效期后会显示“导航提示暂不可用”；不会伪造路口放大图。出现问题时请记录系统及应用版本、前后台状态和操作步骤，并导出诊断日志。公开提交日志前请移除个人位置、路线和其他隐私信息。
